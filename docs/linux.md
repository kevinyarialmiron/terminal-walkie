# Linux

The first supported Linux component is `hablar`, located in
[`linux/hablar`](../linux/hablar/). It accepts text and speaks it with eSpeak
using the Spanish voice.

Install eSpeak with the package manager for the distribution, then follow the
installation instructions in [the component README](../linux/hablar/README.md).

No system-level installation is performed by this repository. The checked-in
script can be invoked directly or installed by the operator in a directory on
their `PATH`.
